# Wisdom Students — Digital Wellbeing Campaign

A responsive campaign microsite for Wisdom Students Kerala, designed to start a thoughtful conversation about screen time, attention, rest, and healthier digital habits.

## Live site

[detox-wisdom.vercel.app](https://detox-wisdom.vercel.app)

## Highlights

- Malayalam-first typography with Noto Sans Malayalam and Manrope
- Interactive screen-time Brain Lab with selectable zones, missions, and balance progress
- Private 16-question digital wellbeing check-in
- Practical reset tools and a seven-day reset planner
- Filterable campaign gallery with a full-screen image viewer
- Responsive design for mobile, tablet, and desktop
- Official Instagram and YouTube links in the footer

## Run locally

This is a static website with no build step.

1. Clone the repository.
2. Open `index.html` in a browser, or serve the folder with any static web server.

For example:

```bash
npx serve .
```

Then open the local URL shown in your terminal.
